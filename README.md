🌐 Personal Portfolio Website (Flask)

A modern and responsive portfolio website built with Python (Flask) to showcase skills, projects, and achievements. 🚀

🎯 Project Overview

This project is a dynamic personal portfolio where you can highlight your profile, resume, projects, and contact details.
It uses Flask as the backend framework with a clean, responsive frontend design.

Perfect for developers, designers, or students who want to host their portfolio website on GitHub or a server. ✨

🔥 Features

Responsive and mobile-friendly design 📱

Home, About, Skills, Projects, and Contact sections 🌟

Dynamic rendering with Flask templates (Jinja2) 🧩

Contact form (optional backend or email integration) 📧

Easy-to-customize structure for personal branding 🎨

Can be deployed on Heroku, Render, or PythonAnywhere 🚀

⚡ Getting Started
1️⃣ Clone the repository
git clone https://github.com/<your-username>/portfolio-flask.git
cd portfolio-flask

2️⃣ Install dependencies
pip install flask

3️⃣ Run the app
python app.py


Now visit http://127.0.0.1:5000/
 in your browser 🎉
